Overview


This binary file is used to configure the DLPC350 DMD Controller at power up. It enables the 0.45 WXGA chipset to display high speed, native resolution patterns with user selectable bit depths, pattern rates and exposure time. To be used with system with the following configuration:

  • DMD: DLP4500
  • Controller: DLPC350
  • Illumination: 3-LED (RGB)
  • I2C Address: 0x34

Release Information:

  • Firmware Version: 4.4.0

Supported Features


This firmware supports Pattern mode (Pixel accurate mode) and regular video projection.

  • Structured light mode:
    • Pixel Accurate Mode with no video processing
    • One-to-One Mapping of Input Data to Micromirrors
    • 1-Bit Binary Pattern Rates up to 4225 Hz
    • 8-Bit Gray Pattern Rates up to 120 Hz
    • Combination of 1-bit to 8-bit patterns with user defined Pattern Exposures

  • Video Projection Mode:
    • Programmable color space coordinate adjustment
    • Programmable color space conversion
    • Programmable Degamma
    • Spatial-Temporal Multiplexing (Dithering)

    Known Issues


    • Displaying more than 1 pattern in external trigger mode will not work properly under the following condition i.e., display more than one pattern with a single external trigger with condition Pattern Period > Pattern Exposure by > 230us. Workaround - Keep Pattern Period = Pattern Exposure;for inserting dark time select Clear DMD after exposure option this will automatically insert 230us dark time.
    • Pausing and resuming the pattern sequence in Variable Pattern Exposure/Pattern Exposure mode causes the colors to shift by one pattern.
    • Cannot go from “Paused” state to “Stop” state while running pattern sequence. Need to start first and then stop.
    • Pausing during first pattern from a splash and resuming sometimes switches to next splash (legacy issue).
    • FPDLink Invert Data Option does not work.
    • FPDLink Pixel Mode 4 does not work.
    • DLPC350 FPD Link and Parallel RGB 8-bit Input modes are not supported. Customers are advised to always set Full 30Bit Input and then define pattern sequences with only the required bits.

    Updates in this Release


    • Release v4.4.0
      • Fixed issue where GPIO Clock cannot be enabled.
      • Fixed issue where green LED would turn ON in StandBy mode when Video mode command is issued.
      • Fixed YUV format support for external parallel sources.
